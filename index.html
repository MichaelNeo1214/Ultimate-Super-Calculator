      📖 Petunjuk Penggunaan

      1. Pilih kategori di Sidebar (desktop) atau Dropdown (HP). 11 kategori: Dasar & Ilmiah, Geometri, Fisika, Keuangan & Kripto, Kesehatan, IT & Server, AI Inference, Sipil & Air, Otomotif, Gaming, Akademik.
      2. Kalkulator dasar: ketik ekspresi / tekan keypad. Hasil live otomatis; tekan = / Enter untuk simpan riwayat. ! = faktorial.
      3. Mode rumus: pilih rumus (mis. ROI, Subnetting, VRAM, Debit, CC, eDPI, IPK), isi input sesuai label. Dropdown satuan bila ada.
      4. Desimal boleh titik/koma. Field bertanda (opsional) boleh dikosongkan.
      5. Hasil real-time + langkah + info tambahan tampil di panel kanan. Salin hasil / Reset tersedia.
      6. Trigonometri: atur Derajat/Radian. log = basis 10, ln = natural.

      📝 Catatan

      • Untuk pembelajaran & estimasi umum, bukan pengganti software teknik/keuangan/medis bersertifikat.
      • Satuan SI konsisten; geometri memakai cm sebagai ilustrasi.
      • Tampilan maks 6 desimal; komputasi presisi penuh double JavaScript.
      • Faktorial 0–170. Trigonometri default derajat.
      • Keuangan/mining bukan nasihat investasi. Mining memakai revenue kotor input (cek pool/WhatToMine); difficulty & fee diabaikan.
      • Subnet IPv4 unicast; /31 ikut RFC 3021. Download/bandwidth abaikan overhead protokol.
      • VRAM/GGUF memakai overhead default; KV-cache prompt panjang tidak dimodelkan rinci.
      • Hidrostatis = gauge. Debit = aliran seragam. CC = volume teoritis.
      • Gacha = peluang binomial independen (kecuali pity). eDPI lintas game tidak identik 1:1.
      • TOEFL = prediksi skala, konversi mentah→skala tiap tes berbeda. IPK contoh 5 MK.
      • BMI WHO, bukan diagnosis medis. Riwayat hanya di localStorage perangkat Anda.
